# @ocr-to-report/sdk

TypeScript SDK for OCR-to-Report. Wired up in Phase 9 — auto-generated from
the OpenAPI 3.1 spec via `openapi-typescript-codegen` plus hand-written
ergonomic wrappers.

```bash
make openapi    # export OpenAPI spec from running API
make sdk-ts     # regenerate TypeScript SDK from spec
```
